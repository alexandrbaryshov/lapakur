# 0002. Логотип выводится CSS-маской из SVG-файла (D02)

## Контекст

Бриф (R14) требует перерисовать логотип 1 в 1 вектором. План предполагал компонент логотипа с inline-SVG и цветом `currentColor`.

## Решение

Логотип выводится CSS-маской из векторного файла логотипа, а не inline-SVG. Цвет задаётся через `currentColor` / фон элемента. Вектор остаётся источником правды, растра нет.

## Почему

- Inline-SVG. Отвергнут: длинный inline-SVG детектор impeccable считает иллюстрацией, а не логотипом, и это ломало проверки сборки.
- Растровый логотип (PNG). Отвергнут заранее брифом: нужен вектор «в хорошем качестве», чёткий на любом экране.
- Маска сохраняет вектор и управление цветом, то есть выполняет R14 и план по цвету.

## Последствия

- Логотип не получает собственного доступного имени и стилизуемых частей: внутри SVG нельзя красить пудель и надпись по отдельности, он один цвет. Если понадобится двухцветный знак, решение придётся пересмотреть.
- Маска зависит от загрузки отдельного файла. Пока он не пришёл, логотип не виден; для критичного первого экрана файл должен грузиться вместе с ним.
- При сборке с пререндером остаются безвредные предупреждения про `url(/media/…)`.
- Решение вызвано поведением конкретного детектора. Если правила детектора изменятся, причина исчезнет, а маска останется.
