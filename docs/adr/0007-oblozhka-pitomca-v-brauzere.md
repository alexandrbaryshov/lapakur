# 0007. Обложка питомца собирается в браузере, голова — по маске MediaPipe со своего хоста

## Контекст

Пользователь попросил: посетитель фотографирует питомца с телефона, и на фото накладывается обложка журнала «Лапакюр» — шапка, имя питомца крупным заголовком, случайная сенсация, строки о студии и контакты. Голова питомца должна слегка заходить на шапку, а при съёмке нужна рамка, чтобы питомец не закрыл всё название. Бэкенда у сайта нет (GitHub Pages), аудитория — в России.

## Решение

- Всё считается в браузере: камера (`getUserMedia`) или фото из галереи → кадр 1080 × 1440 под рамкой-подсказкой → canvas-обложка → JPEG для сохранения и «Поделиться». Фото никуда не отправляется.
- Голова перед шапкой — по альфа-маске DeepLab v3 (MediaPipe Image Segmenter, классы PASCAL VOC: собака, кошка и др.). Маска действует только ниже 45 % высоты заглавных — верх букв виден всегда.
- Всё для сегментации лежит на нашем хосте: JS задачи и wasm берутся из `@mediapipe/tasks-vision` через `?url` (Vite кладёт их в `dist/assets/`), модель — `public/models/deeplab_v3.tflite` (2,7 МБ). Окно — ленивый чанк `CoverStudio`, сегментатор — ещё один (`segment`), грузятся только по нажатию на рамку-приглашение.

## Почему

- Серверная вырезка фона (сторонний API). Отвергнута: нужен бэкенд и ключ, фото уходит третьим лицам, каждая обложка стоит денег.
- CDN Google/jsDelivr для wasm и модели. Отвергнут: доступность из России не гарантирована, а GitHub Pages отдаёт файлы с того же адреса, что и страницу.
- Без сегментации (буквы просто поверх фото). Оставлено запасным путём: если модель не загрузилась, питомца не нашли (меньше 2 % кадра) или включён Save-Data — шапка целиком поверх фото, обложка всё равно собирается.

## Последствия

- Первое открытие камеры тянет ~14 МБ (wasm ~11 МБ, gzip ~3,3 МБ, модель 2,7 МБ, JS ~0,4 МБ). Загрузка идёт в фоне, пока посетитель наводит камеру; обложка показывается сразу, голова встаёт перед шапкой, когда маска готова.
- `scripts/budget.mjs` не считает чанк `CoverStudio-*` первым экраном (`ON_DEMAND_CHUNKS`); JS первого экрана вырос на ~2 КБ gzip только из-за рамки-приглашения.
- Модель знает животных классов PASCAL VOC: на нарядно одетых или необычных питомцах маска бывает пустой — тогда работает запасной путь.
- Камера работает только по HTTPS (GitHub Pages — да) и после разрешения посетителя; без разрешения окно предлагает фото из галереи.
- Сохранение «в галерею»: у сайта нет доступа к «Фото» напрямую. На iPhone загрузка файла уходит в «Файлы», поэтому кнопка открывает меню «Поделиться» с одной картинкой (пункт «Сохранить изображение» кладёт её в «Фото»); на Android картинка скачивается в Download и видна в галерее. Готовая обложка показана картинкой JPEG, а не canvas: удержание пальцем на ней тоже предлагает сохранить в галерею.
