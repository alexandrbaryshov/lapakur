# Проверка стабильности, загрузки и безопасности — 11.11.2026

Изменения локальные, без публикации. Визуальные стили, шрифты, изображения, композиция и тексты штатных состояний не менялись. Проверены снимки 390×844 и 1440×900; это ручной просмотр, не попиксельная проверка всех состояний.

## Изменения

- Общая граница ошибок изолирует сбои загрузки фотопросмотра, камеры, прайса и декоративной линии от основной страницы. Если окно прайса не загрузилось, открываются уже имеющиеся в HTML таблицы. Для фото и камеры добавлены сообщения только на случай ошибки.
- Предзагрузка фотографий закрытых альбомов сохранена: первые три фото каждого альбома, прежний порог 600 px. Ей задан низкий сетевой приоритет. Предзагрузка окна прайса сохранена.
- По согласованию карта начинает загружаться за 1600 px до контактов; таймаут запускается только при её загрузке. При отсутствии IntersectionObserver сохраняется ранняя загрузка.
- Видео приостанавливается в скрытой вкладке и показывает постер при ошибке воспроизведения. Существующие ограничения Save-Data/2G/3G/reduced-motion сохранены.
- SITE_URL проверяется и экранируется перед вставкой в HTML; строки с `$&` больше не повреждают разметку через механизм replace.
- Устранены известные уязвимости инструментов разработки: Vitest 5.1.0, sharp 0.35.5, typescript-eslint 8.72.2 с целевым override minimatch 11.0.1+. npm audit добавлен в CI.
- Добавлены повторяемый локальный нагрузочный тест и ограничение ожидания команд CDP в браузерной проверке.

## Проверки

`npm run check`: 15 файлов, 192 теста, типизация, ESLint, сборка и бюджет — успешно. Сохранилось предупреждение jsdom о неподдерживаемой навигации внешней ссылки; SSR-сборка также выдаёт прежние предупреждения о публичных ресурсах в неиспользуемом SSR CSS. Маркеров `__VITE_PUBLIC_ASSET__` в итоговом HTML нет.

Бюджет: JS 110,2 КБ gzip при лимите 120 КБ; расчёт критических ресурсов 290,0 КБ при лимите 300 КБ (до изменений 289,7 КБ). Рефакторинг улучшает порядок загрузки и устойчивость; уменьшения размера бандла не заявляется. Бюджет — расчётный, а не сумма всех фактических запросов браузера.

### Медленная сеть

Chrome, 390×844, DPR 3, холодный браузерный кеш, первый визит со шторкой; задержка 562,5 мс, скорость 1,44 Мбит/с, без прокрутки. По одному замеру до/после, без статистического утверждения об ускорении на всех устройствах. После изменений замер выполнялся одновременно с локальным нагрузочным тестом.

Шторка была показана, поэтому LCP не следует интерпретировать как время показа обложки после её открытия. Сырые результаты: `network-baseline.json`, `network-slow4g.json`.

### Безопасность

`npm audit` до обновления: 11 записей (2 critical, 1 high, 8 moderate), все в инструментах разработки. После: 0 известных уязвимостей во всех зависимостях, включая dev; отчёт `npm-audit.json`. Это состояние базы npm на момент проверки, не гарантия отсутствия неизвестных уязвимостей.

Проверены опасные DOM-вставки, сетевые обращения, обработка фото и камеры, внешние ссылки и сборка.
