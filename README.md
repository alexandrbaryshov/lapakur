# Лапакюр

Основной рабочий Git-репозиторий: `D:\Codex\Websites\lapakur v2`.
Ветка `master` продолжает публичную историю `origin/master`.

## Работа

- `npm ci` — зависимости (Node 24+).
- `npm run dev` — локальная разработка.
- `npm run check` — типы, ESLint, тесты, сборка и бюджет загрузки.
- `git push origin master` — отправка проверенных коммитов; GitHub Actions публикует Pages.

Создавать отдельные папки экспорта больше не нужно. Не отправляйте архивную ветку через `git push --all`.

## Мобильная загрузка

Фотографии отзывов используют WebP (376 КБ вместо 1528 КБ для восьми файлов).
При Save-Data, reduced-motion или определяемом браузером соединении 2G/3G
вместо автоматического видео остаётся постер. Если Network Information API отсутствует,
сохраняется обычное воспроизведение. Шрифты и фирменная композиция сохранены.
